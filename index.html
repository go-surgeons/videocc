動画字幕の多言語切り替え PoC

教材動画「EMI ノットプッシャー EMICS150、150C の使い方」(11 分、無音、4:3)に ja と en の WebVTT を <track> で添えて、プレイヤーの描画方式ごとの見え方を比べる。 字幕はスライドと焼き込み字幕の文字起こしで、時刻は ±5 秒の目安。設定は URL に載るので、この URL をそのまま実機の Safari や iPhone に送れる。

この PoC で確かめること
  1. CC ボタンと上の言語ボタンの両方で ja / en / オフが切り替わるか。
  2. 拡大を 200% にしたとき、字幕が動画と一緒に拡大されて切れるか。Chrome と Firefox では Video.js が .vjs-text-track-display に描くので切れない見込み。Safari ではネイティブ描画なので切れる見込み。
  3. Safari で「Video.js (nativeTextTracks:false)」に切り替えると、描画が vtt.js に寄って切れなくなるか。
  4. iPhone で playsinline を外したとき、再生でネイティブ全画面に入るか。そのとき字幕が出るか、極端に小さくならないか。
  5. 4:20〜9:05 の実演には焼き込み字幕がある。<track> の字幕と重なってどう見えるか(5:05 付近)。
  6. 3 行の cue (1:02 や 3:00 付近)がどう折り返されるか。
